# Жизнь Гровера 3D

В Украине выращивание конопли без лицензии незаконно, материал образовательный.

Закрытая образовательная 3D-игра проекта ALL BINGO S++. Сама игра в этом репозитории не хранится: после входа по email файлы загружаются только для адресов из списка допущенных.

Играть: <https://makiavelli-maker.github.io/grower3d/>

Реальной оплаты, сбора паспорта и платёжных данных нет.
