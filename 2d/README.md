# Жизнь Гровера 2D

В Украине выращивание конопли без лицензии незаконно, материал образовательный.

Закрытая образовательная 2D-игра проекта ALL BINGO S++ (тёмный комикс, тент, NPK, автономия, тревоги). Сама игра в этом репозитории не хранится: после входа по email файлы загружаются из закрытого хранилища только для адресов из списка допущенных.

Играть: <https://makiavelli-maker.github.io/grower3d/2d/>

3D-версия: <https://makiavelli-maker.github.io/grower3d/>

Реальной оплаты, сбора паспорта и платёжных данных нет.
